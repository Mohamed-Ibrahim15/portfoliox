# Mohamed — Professional Front-End Developer Portfolio

A modern, high-performance, and fully responsive developer portfolio built with **React**, **Vite**, and **Modern CSS**.

## 🚀 Featured Projects Included

1. **Nutrition System (Health & Fitness)**
   - Smart diet & meal planning web application.
   - Interactive daily calorie & macronutrient tracker (Protein, Carbs, Fats).
   - Food database search and animated progress indicators.
   - Responsive health analytics dashboard.

2. **E-Commerce Platform (Full Featured Store)**
   - Modern online store with dynamic product catalog filtering and instant search.
   - Global cart and wishlist state management with Redux Toolkit and LocalStorage persistence.
   - Multi-step checkout flow, product rating reviews, and variant selector.

3. **Travel World (Travel & Exploration)**
   - Global destination discovery and tour booking portal.
   - Interactive destination explorer with weather insights.
   - Trip cost calculator, itinerary builder, and package booking engine.

## 🛠️ Features & Highlights

- **Modern Glassmorphism UI**: High-end dark/light theme switching with smooth transitions and persistent state in localStorage.
- **Interactive Project Mockups**: Rich visual application previews for each project rather than static placeholders.
- **Project Case Study Modal**: In-depth overview, architecture breakdown, and key features modal.
- **Services & Skills Showcase**: Clean categorized tech stacks with icons and proficiency highlights.
- **Interactive Contact Hub**: Direct WhatsApp chat integration, one-click email copying with visual feedback, and mailto contact form.
- **Optimized & Fast**: Built with Vite for instant HMR and under 2-second production builds with zero heavy external dependencies.

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## ⚙️ Customization

- **Content & Projects**: Edit [`src/data.js`](src/data.js) to update your name, bio, social links, project links, and experience.
- **Design & Themes**: Edit CSS variables in [`src/styles.css`](src/styles.css) (`--accent`, `--bg`, `--card`, etc.).
- **Components & Layout**: Edit [`src/App.jsx`](src/App.jsx).

## 🌐 Deployment

Ready for one-click deployment on **Vercel**, **Netlify**, or **GitHub Pages**:
- Build command: `npm run build`
- Output directory: `dist`
